# TeamProject Manager

## Назначение
Приложение для управления командными проектами. Позволяет создавать проекты, назначать команды, ставить задачи и отслеживать их выполнение.

## Целевая аудитория
Руководители команд, тимлиды, участники проектных групп, желающие структурировать работу над проектами.

## Описание предметной области
Управление проектами (Project Management). Основные процессы: создание проекта, формирование команды, постановка и распределение задач, контроль статуса выполнения.

## Основные сущности
- **Проект (Project)**: Название, описание, дата начала, дата окончания, статус (активен/завершен).
- **Команда (Team)**: Название, описание, список участников.
- **Участник (Member)**: Имя, роль, контактная информация.
- **Задача (Task)**: Название, описание, статус (новая, в работе, выполнена), срок выполнения, ответственный участник.

## Основные функции
- Создание нового проекта.
- Добавление участников в команду проекта.
- Создание и назначение задач по проекту.
- Отображение списка проектов с их статусами.
- Просмотр списка задач по проекту.

## Структура проекта
- `main.py` — точка запуска, меню приложения;
- `projects.py` — функции работы с проектом и участниками;
- `tasks.py` — функции работы с задачами;
- `storage.py` — сохранение и загрузка данных в JSON;
- `utils.py` — вспомогательные функции безопасного ввода;
- `data/` — файлы данных проекта (`projects.json`, `tasks.json`);
- `tests/` — автоматизированные тесты.

## Формат хранения данных
Данные о проекте и участниках хранятся в `data/projects.json`, данные о задачах — в `data/tasks.json`. Оба файла загружаются при запуске и сохраняются при выходе из программы.

## Требования
- Python 3.x
- pytest
- flake8

Установка зависимостей:

pip install -r requirements.txt


## Запуск программы

python main.py


## Запуск тестов

pytest


## Проверка качества кода

flake8


## План развития проекта
На следующих этапах планируется:
- преобразование сущностей проекта в классы (ООП, ПР3);
- разработка веб-приложения на Django;
- подключение базы данных (SQLite/PostgreSQL);
- реализация аутентификации пользователей;
- разработка REST API для управления сущностями;
- контейнеризация приложения с помощью Docker;
- настройка CI/CD.
